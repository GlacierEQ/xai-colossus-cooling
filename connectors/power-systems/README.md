# Phase 6 — Power Systems

Dual 500MW substations, 8 on-site gas turbines, battery UPS strings, ATS/STS switching, and N+2 redundancy control for xAI Colossus v2.

## Scope
- Utility intake management
- Substation health telemetry
- Turbine dispatch + black-start logic
- UPS battery autonomy and transfer controls
- Emergency load shedding tiers
- Grid islanding orchestration

## Target KPIs
| KPI | Target |
|-----|--------|
| Total power capacity | 1 GW utility + on-site generation |
| Turbine count | 8 |
| UPS ride-through | >= 15 minutes |
| Transfer switch time | < 100 ms |
| Grid failover | < 5 s |
| Redundancy | N+2 |
